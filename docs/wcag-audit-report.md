# VTK Website WCAG 2.2 Level AA Audit Report

**Audit date:** 2026-11-18  
**Target conformance:** **WCAG 2.2 Level AA** (per [CLAUDE.md](../CLAUDE.md#L287-L328) and [wcag-plan.md](./wcag-plan.md))  
**Scope:** Public and member-facing `vtk.be` (`apps/web` excluding `/admin` and `(scanner)`, plus shared `packages/ui` primitives excluding `AdminNav*`) across Dutch (`/`) and English (`/en`).

## 1. Executive Summary & Conformance Snapshot

This audit combined four layers across **279 in-scope source files** (225 `.tsx` files + 54 `.ts`/`.css` files) and **live rendered Chromium inspection** on `http://127.0.0.1:3014`:

1. **Programmatic contrast & CSS scan (`contrast_audit.py`)**: Exact sRGB relative-luminance calculations with alpha compositing across `vtk-base.css`, `globals.css`, and `vtk-ticket-colors.css`.
2. **AST lint scan (`eslint-plugin-jsx-a11y` strict)**: Flagged **70** raw JSX accessibility warnings across **25** `.tsx` files (verified in context by Wave 1 shards; true defects retained, WAI-ARIA/dialog false positives filtered out).
3. **Wave 1 (7 parallel read-only shards `S1`-`S7`)**: Inspected all **279** files with zero overlap and produced **156** raw static findings.
4. **Wave 2 (3 live browser agents `B1`, `B2`, `B3`)**: Tested rendered routes at `1440x900` (`:root { zoom: 0.9 }`) and `320x640` mobile reflow, keyboard-only navigation, dialog focus traps, sticky-header focus obscuration (`2.4.11`), target spacing (`2.5.8`), and authenticated flows (`sport@vtk.prototype`).

After collapsing duplicate page-level symptoms into shared root causes (tokens, `[locale]/layout.tsx`, `ConfirmDialog`, `FormFieldBlock`, `Markdown`, nested `<main>`, modal focus management), the **156 raw Wave 1 findings** and **Wave 2 browser observations** consolidate into **57 grouped root-cause items** (`A11Y-001` through `A11Y-057`) across 7 domains:

### Verified Strengths Already in Place

- **Language & Metadata (`3.1.1`)**: `RootLayout` derives initial `<html lang>` (`nl-BE` / `en`) from `proxy.ts`'s `x-pathname` header (though client-side locale switches need `document.documentElement.lang` sync).
- **Homepage Hero (`BlueprintHero`)**: Decorative SVG carries `aria-hidden="true"`, provides an `.sr-only` `<h1>`, includes `@media (prefers-reduced-motion: reduce)`, and draws crisp `2px solid var(--yellow)` `:focus-visible` outlines.
- **Opening Hours & Shifts Screen-Reader Text**: `OpeningHoursBand` provides complete `.sr-only` text for visual timelines; `RewardCoins` uses `role="img"` + `aria-label`; `RunnerStats` pairs SVG charts with `<figcaption>` and `RunnerLapTable`.
- **Scroll-Driven Motion (`vtk-motion.css`)**: Properly gated inside `@supports (animation-timeline: view())` and `@media (prefers-reduced-motion: no-preference)`.
- **Mobile Reflow (`1.4.10`)**: `B3` verified `0px` horizontal overflow (`scrollWidth === 320`) across `/`, `/kalender`, `/tickets`, `/en/contact`, and `/inloggen` at `320x640`.
- **Shared Primitives**: `IconButton` / `DeleteIconButton` enforce `size-8` (`28.8px` zoomed) and require `label`/`srLabel`; `AccountTabs` implements full WAI-ARIA Tabs with arrow-key navigation; `ExclusiveChoiceGroup` uses `role="radiogroup"` with native wrapped radio labels; `SemesterTabs` uses `<nav>` + `aria-current="page"`; `vtk-ticket-colors.css` passes `>= 5.63:1` for all 7 ticket hues.

### Live Audit Scope Constraints & Operational Blockers Discovered

- **Webpack dev crash on `/media` & `/fotos`**: Visiting `/media` or `/fotos` under `next dev --webpack` failed with `Module not found: ESM packages (pdfjs-dist/build/pdf.worker.min.mjs) need to be imported` at `apps/web/app/[locale]/media/MagazineShelf.tsx:116:45`, leaving subsequent webpack routes in an HTTP 500 state until dev server restart. Live DOM checks on `/media` could therefore not complete (`S4` static findings cover those files completely).
- **NL Redirect loop on dev (`/contact`, `/privacy`, `/shift`)**: Navigating to `/contact` and `/privacy` aborted with `ERR_TOO_MANY_REDIRECTS` due to `LEGACY_REDIRECTS` (`/nl/contact` -> `/contact` in `apps/web/lib/legacyRedirects.ts:117-126`) interacting with `proxy.ts` rewriting bare paths to `/nl/...`. Live checks used `/en/contact`, `/en/privacy`, and `/en/shift`.
- **Empty Dev DB States**: `/account#mijn-vtk-tickets`, `/en/shift`, `/theokot`, and `/formulieren` had no active tickets/shifts/sale days/open forms in the local dev DB, and `sport@vtk.prototype` redirected from `/pal-plus` to `/ledenportaal`; `TicketQrModal`, `ShiftBoard`, `TheokotOrderClient`, and `PublicForm` active form rendering remain verified statically via Wave 1 (`S4`, `S5`, `S7`).
- **Browser Sandbox Limits**: `B3` could not execute `200%` root font scaling (`1.4.4`) or `prefers-reduced-motion: reduce` emulation (`2.2.2`) because the sandbox worker isolates `document` and omits `page.emulateMedia()`; both are covered statically in `S1`, `S3`, and `S5`.
- **Dev Overlay Attribution Note**: `B1` observed an unlabeled hidden `<nav>` and an empty hidden `<h2>` across pages; inspection of `EditorialNavLinks.tsx` and `Header.tsx` confirmed app `<nav>` elements carry `aria-label` (desktop + `hidden` mobile drawer), and the empty hidden `<h2>` / unlabeled `<nav>` came from Next.js DevTools `<nextjs-portal>` in dev mode rather than application markup.
